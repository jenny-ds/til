# API에 대하여

## 오늘 배운 것

- API는 다른 소프트웨어의 데이터에 접근하거나 기능을 호출할 수 있게 하는 소통 규칙이다.
- 요청 방식인 HTTP 메서드는 GET(조회), POST(생성), PUT(수정), DELETE(삭제) 4가지다.
- API로 데이터를 주고받을 때는 JSON 형식을 쓰고, key-value 쌍 구조다.

## 상세 내용

AI로 바이브 코딩을 하다 보면 API를 사용하게 되는데, API는 무엇인가?
API는 Application Programming Interface의 줄임말로, 다른 소프트웨어에서 제공하는 데이터에 액세스하거나 기능을 호출할 수 있도록 하는 소통 규칙이다.

API에 요청을 할 때는 목적에 따라 크게 4가지 방식으로 요청을 할 수 있는데, 이를 HTTP 메서드라 한다.

1. GET: 데이터 조회
2. POST: 데이터 생성
3. PUT: 데이터 수정
4. DELETE: 데이터 삭제

API를 통해 데이터를 주고받을 때는 JSON 형식을 사용하는데, 바이브 코딩을 하면서 직접 작성할 일은 많지 않겠지만 JSON이 무엇인지는 알아두면 좋겠다.
JSON은 사람이 읽기 쉽게 되어 있어서 어렵지 않다.
기본적으로 key-value 쌍의 구조로 되어 있다.

```json
{
  "name": "홍길동",
  "age": 25
}
```
